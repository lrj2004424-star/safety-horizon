# 02 Operator Runbook / 操作顺序

1. 确认只运行一个实例；避免旧项目和发布包同时采同一个窗口。
2. 按 [macOS](../platforms/macos/README.md) 或 [Windows](../platforms/windows/README.md) 完成安装与环境检查。仅 macOS 窗口采集需要编译助手和录屏授权。
3. 窗口输入先打开萤石直播；RTSP 确認授权地址可用。确认日期时间、机位、目标左侧工位、裁切及遮挡，不把录像回放标为实时。
4. 启动对应平台的 `02_run`，按菜单选择输入。第一次保持默认静音，不接机器控制装置。
5. 查看浏览器中的新鲜视频、姿态与待审核队列；低置信或源过期要现场确认。
6. 选择预警 → 等待证据 READY → 逐帧回放 → 标注手部、动作、遮挡 → 选择 1–5 级 → 提交。
7. 收到保存成功回执后检查 `src/annotations/_records`；每日导出文件由同一存储层维护。
8. “补录漏报”用于系统未报但人工发现的样本，“正常样本抽检”用于负样本。只统计系统报警样本不能得出完整漏报率。
9. 阈值建议必须人工审批，下一次视觉引擎启动生效，并重新做现场评估。
10. 退出使用启动终端 Ctrl+C。不要只关浏览器就认定声音/采集已停止。

Windows 窗口被遮挡/最小化或视频源断开时，采集可能停止并联动关闭本次会话。恢复视频后重新运行 `02_run`；不要把旧预览当作实时画面。

## Review inputs / 标注含义

- 手部 SAFE / CAUTION / DANGER / NOT_VISIBLE 分别表示安全、注意、危险、无法判断。
- 动作 NORMAL_PICK / WASTE_CLEANUP / VIOLATION / STYLE_CHANGE / OTHER。
- “标注当前帧”只写入界面草稿；点击提交且服务成功确认后才落盘。
- 人工评定 3–5 级是提醒授权条件之一，不是受伤已发生的标签。
- 不填写员工姓名、身份证或无关个人信息。

## Evidence duration / 证据时间

目标前 3 秒 + 后 5 秒不是每次必然完整；启动不足 3 秒、退出或断流可能缺帧。以片段状态、元数据与帧时间为准。不能把补录后的新画面伪装成故障前证据。
